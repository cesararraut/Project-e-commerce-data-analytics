# Paste-ready BigQuery schemas for the console
#
# In BigQuery Console > Create table > Schema, UNTICK 'Auto detect',
# click 'Edit as text', and paste the single line for that table.
# Every column is STRING on purpose - this is a raw layer (IDs included: they are labels, not numbers).
